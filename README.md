# Georgii
### Software Engineer & System Architect

I design and develop complex systems: from robust data pipelines to interactive web interfaces and Telegram Mini Apps architecture. 

My focus is clean architecture, fault tolerance, and system predictability. I prefer Python on the backend and React/Expo on the frontend, delegating infrastructure to reliable, production-ready solutions (Supabase, Docker).

## 🏗 Key Competencies & Engineering

* **Telegram Mini Apps & P2P Systems**
  Designing client bots and mini-apps (Aiogram 3, FastAPI, Supabase). Experience integrating external crypto exchanges (Bybit API) to build currency exchange architectures.
* **Data Engineering & ETL Pipelines**
  Developing fault-tolerant crawlers and parsers (Python, Playwright, SQLite, Pandas) for collecting and aggregating unstructured data from marketplaces and classifieds.
* **Full-stack Development & Integrations**
  Building cross-platform mobile apps (React Native / Expo) and web platforms (React, Tailwind, Vite). Example: a real estate aggregator with a unified database and real-time chats.
* **Event-Driven Systems**
  Developing synchronously managed systems. Example: [Ratarui](https://argoonid.github.io/Ratarui/) — infrastructure for a gastronomic dinner with synchronized course serving, orchestrated via a Telegram bot.
* **Custom UI/UX (Pet Project)**
  An interactive web hub for piano learning featuring custom rendering (falling notes visualization) for synthesizers.

## 🛠 Tech Stack

* **Backend:** Python, FastAPI, Aiogram 3, SQLite, Pandas, Playwright, PostgreSQL, SQLAlchemy
* **Frontend:** React, React Native, Expo, Tailwind CSS, Vite
* **Infrastructure & BaaS:** Supabase, Docker, GitHub Pages, Cloudflare
